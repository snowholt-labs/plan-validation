Plan Validation provides three skills for revising prompts without execution and checking an implementation plan against its approved specification and the current code before handing it to another agent session.

Start with **[Get started](/plan-validation/get-started/)**, then follow **[Your first run](/plan-validation/first-run/)** in a repository containing a saved plan and specification.

| Guide | Contents |
| --- | --- |
| [Get started](/plan-validation/get-started/) | Claude Code plugin, Codex skills, updates and removal |
| [Your first run](/plan-validation/first-run/) | Inputs, worktree selection and focused validation |
| [Reports and handoffs](/plan-validation/reports-and-handoffs/) | Eight report sections, scores, evidence and freshness |
| [Safety and limitations](/plan-validation/safety-and-limitations/) | Permissions, command execution, privacy and verification limits |
| [Troubleshooting](/plan-validation/troubleshooting/) | Discovery problems, missing dependencies and historical reports |

The [repository](https://github.com/snowholt-labs/plan-validation) contains the skills, tests and a [reproducible demonstration](/plan-validation/examples/). This is an independent pilot project. It is not affiliated with Anthropic, OpenAI or Superpowers.

See the [changelog](/plan-validation/changelog/) when upgrading.
