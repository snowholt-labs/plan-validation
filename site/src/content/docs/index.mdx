<h1 id="_top" class="pv-headline" data-pagefind-meta="title:Overview">Rehearse the plan before you hand it to a coding agent.</h1>

<p class="pv-lede">Three agent skills for prompt revision and the gap between an approved specification and implementation: check the plan against the code, rehearse its instructions in a disposable worktree, and keep a complete evidence report for the next session.</p>

> **Pilot release:** the package and deterministic renderer are tested separately from agent behavior. The example is an authored, reproducible fixture—not a benchmark or a claim of independently validated agent performance.

## Install

<Tabs>
  <TabItem label="Claude Code">

In your terminal:

```bash
claude plugin marketplace add snowholt-labs/plan-validation
claude plugin install plan-validation@snowholt-plugins
claude plugin list
claude plugin details plan-validation
```

  </TabItem>
  <TabItem label="Codex">

Inside Codex, request all three skills from the built-in installer:

```text
$skill-installer install validate-plan, validation-args and revise-prompt from https://github.com/snowholt-labs/plan-validation, using skills/validate-plan, skills/validation-args and skills/revise-prompt.
```

  </TabItem>
</Tabs>

Needs Git and Python 3.10 or later. [Get started](/plan-validation/get-started/) covers requirements, updates and removal.
