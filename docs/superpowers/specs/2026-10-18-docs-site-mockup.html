Rehearse the plan before you hand it to a coding agent.

Three skills for Claude Code and Codex that check an implementation plan against your code, try its steps in a throwaway worktree, and save the evidence in one report.

Works with ordinary Markdown plans. Nothing ships until you say so.

plan.md, phase 2: retry with backoffexamples/retry
  1. ✓Every requirement has a task and a test
  2. ✓All referenced files exist at the recorded commit
  3. !Retry delay has no cap: check failed with 64 != 30
  4. ✓Fresh reviewer read the revised plan

Install

Run these in your terminal, then start a fresh session in your project.

# Add the marketplace and install
claude plugin marketplace add snowholt-labs/plan-validation
claude plugin install plan-validation@snowholt-plugins

# Then, inside a session
/plan-validation:validate-plan
Needs Git and Python 3.10+. Verified on Linux.
