# Plan Validation

Plan Validation provides three skills for revising prompts without execution and checking an implementation plan against its approved specification and the current code before handing it to another agent session.

Start with **[Installation](https://github.com/snowholt/plan-validation/wiki/Installation)**, then follow **[Usage](https://github.com/snowholt/plan-validation/wiki/Usage)** in a repository containing a saved plan and specification.

| Guide | Contents |
| --- | --- |
| [Installation](https://github.com/snowholt/plan-validation/wiki/Installation) | Claude Code plugin, Codex skills, updates and removal |
| [Usage](https://github.com/snowholt/plan-validation/wiki/Usage) | Inputs, worktree selection, focused validation and first run |
| [Reports and handoffs](https://github.com/snowholt/plan-validation/wiki/Reports-and-Handoffs) | Eight report sections, scores, evidence and freshness |
| [Safety and limitations](https://github.com/snowholt/plan-validation/wiki/Safety-and-Limitations) | Permissions, command execution, privacy and verification limits |
| [Troubleshooting](https://github.com/snowholt/plan-validation/wiki/Troubleshooting) | Discovery problems, missing dependencies and historical reports |

The [repository](https://github.com/snowholt/plan-validation) contains the skills, tests and a [reproducible demonstration](https://github.com/snowholt/plan-validation/blob/main/examples/README.md). This is an independent pilot project. It is not affiliated with Anthropic, OpenAI or Superpowers.

Documentation is versioned in [`docs/wiki/`](https://github.com/snowholt/plan-validation/tree/main/docs/wiki); the wiki is its published reading surface. See the [changelog](https://github.com/snowholt/plan-validation/blob/main/CHANGELOG.md) when upgrading.
